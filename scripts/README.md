# Reconstructed Flow Scripts

These TCL files are intentionally labeled **reference** scripts. They reconstruct the flow sequence described in the SCL internship report and standard Cadence Genus/Innovus practice; they are not presented as the original internal scripts used during the internship.

This distinction matters for interview credibility: the repository demonstrates understanding of the flow and the commands required to reproduce it while avoiding fabricated claims about exact internal automation that was not supplied.
