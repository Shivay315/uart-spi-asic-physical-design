# SPI Master — Implementation Evidence

**Source:** SCL internship report, Chapter 7.6, report pages 67–70.

The report describes a configurable SPI master containing a clock generation unit, FSM, shift register and bit counter, with programmable clock divider and CPOL/CPHA support. It states that the design was synthesized in Cadence Genus and physically implemented in Cadence Innovus through floorplanning, placement, CTS, routing and post-route optimization.
